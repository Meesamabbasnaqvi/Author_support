# General inquiry

Use for questions that do not fit the other five categories, such as updating a book description or other metadata.

## Policy

- Metadata updates can be submitted through the dashboard or by emailing the BookLeaf team.
- Changes typically reflect on platforms within 3 to 5 business days.

## How to answer

- Answer directly if the answer is in this document.
- Say how the author can make the change (dashboard or email), then give the 3 to 5 business day timeline.
- If the question is outside this document, say the team will reply.

## Sample Q&A (calibration)

**Q:** Can I update the description of my book on Amazon after it's already live?
**Expected:** Yes. Metadata updates can be submitted through the dashboard or by emailing the BookLeaf team. Changes typically reflect on platforms within 3 to 5 business days.
